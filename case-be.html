Змяненне рэгістру тэксту анлайн

Бясплатны анлайн інструмент для імгненнага пераўтварэння тэксту ў любы фармат напісання. Падтрымлівае кірылічнае і лацінскае пісьмо без рэгістрацыі.

camelCase
Першае слова з малой, кожнае наступнае з вялікай, без прабелаў. Стандарт у праграмаванні.
прывіт свет → прывітСвет
snake_case
Усе словы з малой, раздзеленыя падкрэсліваннем. Выкарыстоўваецца ў Python і SQL.
прывіт свет → прывіт_свет
kebab-case
Усе словы з малой, раздзеленыя злучком. Стандарт для URL і CSS.
прывіт свет → прывіт-свет

Калі выкарыстоўваць

  • Фарматаванне кода — camelCase для JS, snake_case для Python, kebab-case для CSS
  • Выпраўленне тэксту — прыбраць выпадковы CAPS LOCK
  • Загалоўкі — Кожнае Слова для назваў артыкулаў і прэзентацый
  • URL-адрасы — kebab-case для чытэльных спасылак

Частыя пытанні

Якія мовы падтрымліваюцца?
Любы тэкст — кірыліца і лацініца. Рэгістр змяняецца карэктна для ўсіх сімвалаў.
Што такое camelCase?
Стыль напісання дзе кожнае новае слова пачынаецца з вялікай літары без прабелаў: getUserName. Выкарыстоўваецца ў JavaScript, Java, C#.
Дадзеныя захоўваюцца?
Не. Усё адбываецца ў браўзеры. Тэкст не перадаецца на сервер.
